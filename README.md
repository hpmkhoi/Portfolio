## 🌟 Giới Thiệu (Overview)

Portfolio website mang ngôn ngữ thiết kế **Architectural Editorial & Cinematic Motion**, lấy cảm hứng từ phong cách thẩm mỹ của [illoca](https://illoca.unseen.co/) với tone màu chủ đạo là espresso brown đậm, kem ngà luxury, cùng các chi tiết thước đo kiến trúc, grid drafting blueprint và film grain texture.

Website được tối ưu hóa cho trải nghiệm mượt mà, chuyển động điện ảnh và tích hợp mô hình 3D tương tác.

---

## 🚀 Công Nghệ Sử Dụng (Tech Stack)

- **Core:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS, PostCSS, Custom Film Grain & Drafting Grid CSS
- **Smooth Scroll:** [@studio-freight/lenis](https://github.com/darkroomengineering/lenis) (Hardware-accelerated inertia scrolling)
- **Animation & Motion:** [GSAP](https://github.com/greensock/GSAP) (ScrollTrigger, velocity transforms) & Framer Motion
- **Interactive 3D Engine:** [Three.js](https://threejs.org/) (Custom 3D Director's Lens Core Easter Egg with mouse drag physics & lighting)
- **Creative Components:** Inspired by [React Bits](https://github.com/DavidHDev/react-bits) (SpotlightCard, ShinyText, TiltedCard, SplitText)
- **Icons:** Lucide React

## 💻 Cài Đặt & Chạy Môi Trường Cục Bộ (Getting Started)

### Yêu Cầu
- Node.js >= 18.x
- npm >= 9.x

### Cài đặt dependencies
```bash
npm install
```

### Chạy môi trường Development
```bash
npm run dev
```
Mở trình duyệt tại `http://localhost:5173/`.

### Build Production
```bash
npm run build
```
Thư mục xuất bản: `dist/`.
